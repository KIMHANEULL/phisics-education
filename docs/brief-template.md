# 팀장에게 보내는 브리핑 템플릿

"물리 사이트 만들어줘"처럼 한 줄로 던지면 팀장도 어디서부터 나눌지 모릅니다.
**끝났을 때의 모습**을 먼저 적으세요. 아래 4줄을 채워서 Claude에게 보내면 됩니다.

```
1. 결과: (끝나면 손에 쥘 것 한 가지 — 눈으로 확인할 수 있는 것)
2. 맥락: (누구를 위한 것이고, 지금 무엇이 있는지 한두 줄)
3. 제약: (하면 안 되는 것 / 꼭 지켜야 하는 것)
4. 질문 기준: 내 결정이 꼭 필요할 때만 물어봐.
```

## 예시

```
1. 결과: 고1 학생이 발사 각도와 속도를 바꿔 보며 포물선 운동을 체험하는
   웹 시뮬레이션 페이지 1개 (sims/projectile/index.html) + 학습지 1장.
2. 맥락: 내가 다음 주 수업에서 태블릿으로 보여줄 거야. 지금 저장소는 비어 있어.
3. 제약: 외부 서버 없이 파일 하나로 열려야 함. 공기저항은 켜고 끌 수 있게.
   유료 서비스나 결제 필요한 건 쓰지 마.
4. 질문 기준: 내 결정이 꼭 필요할 때만 물어봐.
```

## 잘 됐는지 확인하는 법

- 팀장이 일을 여러 개로 나눠 직원(서브에이전트)들에게 넘기면 제대로 된 것.
- 되묻기만 반복하면 **1번 결과 줄**을 더 구체적으로 고쳐서 다시 보내세요.
